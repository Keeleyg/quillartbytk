A made-to-order personalised name piece featuring crisp white block
letters set against a lavish background of pink quilled flowers,
swirls, tulips and leaves. The example shown features the
name 'Heidi'. Each piece is built up by hand over many hours of layered
quilling work - see the process photos in this listing for a glimpse of
how it comes together.
