# Product Images

## Naming Convention

Use the format `piece-{id}.jpg` where `{id}` matches the product ID in `products.json`.

Examples:
- `piece-001.jpg`
- `piece-002.jpg`
- `piece-003.jpg`

## Recommended Specs

- **Format:** JPEG (.jpg) — best balance of quality and file size for photos
- **Dimensions:** At least 1200px on the longest side (displays well in lightbox on desktop)
- **Aspect ratio:** 4:3 preferred (matches gallery card layout), but any ratio works
- **File size:** Aim for under 300 KB per image — compress with [Squoosh](https://squoosh.app/) or similar
- **Colour space:** sRGB (standard for web)
- **Background:** Neutral or white backgrounds photograph best

## Tips

- Photograph artwork in natural, diffused light to show the 3D texture of quilling
- Include a straight-on shot as the primary image
- Keep filenames lowercase with hyphens (no spaces)
